VitaNova is a centralized blood donation and coordination platform that connects donors, patients, hospitals, and blood banks. This guide explains how different users interact with the system.

---


## Registration

Users can create an account by providing required personal information and selecting their user role.

Available roles include:

- Donor
- Patient
- Hospital
- Blood Bank

After registration, users can log in and access features available to their role.

---

# Authentication

## Login

Users log in using their registered credentials.

Successful authentication grants access to the appropriate dashboard.

## Password Recovery

Users can reset forgotten passwords through the password recovery process.

---

Donors can:

- Create and update donor profiles
- Provide blood group information
- Manage availability status
- View donation opportunities
- Respond to blood requests
- Track donation history

---

Patients can:

- Create patient profiles
- Submit blood requests
- View request status
- Receive notifications
- Track blood request progress

---

Hospitals can:

- Manage hospital profiles
- Create blood requests
- View available blood inventory
- Manage blood issues and donations
- Coordinate with donors and blood banks

---

Blood banks can:

- Manage blood inventory
- Track available blood units
- Process blood issues
- Coordinate blood availability

---

Users receive notifications related to:

- Blood requests
- Donation updates
- Verification status
- System activities

---

# Dashboard

Each user has access to a personalized dashboard containing information and actions relevant to their role
