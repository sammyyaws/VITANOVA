Testing was performed to ensure VitaNova functions correctly across user registration, authentication, blood management, and request handling.

---

# Testing Approach

The system uses:

- Functional testing
- API testing
- User interface testing
- Validation testing
- Integration testing

---

# Functional Testing

## User Registration

Test:
Create accounts for different user roles.

Expected Result:
Users are successfully registered and stored.

---

## Authentication

Test:
Login using valid and invalid credentials.

Expected Result:
Valid users gain access while invalid credentials are rejected.

---

## Blood Request

Test:
Patient submits a blood request.

Expected Result:
Request is created and visible to relevant users.

---

## Donation Process

Test:
Donor responds to a donation request.

Expected Result:
Donation information is recorded.

---

## Inventory Management

Test:
Hospital or blood bank updates inventory.

Expected Result:
Available blood units are updated correctly.

---

# API Testing

API endpoints were tested to verify:

- Correct responses
- Authentication requirements
- Data validation
- Error handling

---

# User Interface Testing

The frontend was tested for:

- Responsive layouts
- Form validation
- Navigation
- Dashboard functionality

---

# Security Testing

Test were performed to verify:

- Protected endpoints
- User permissions
- Authentication restrictions
