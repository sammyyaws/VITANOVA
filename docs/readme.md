VitaNova Documentation


This directory contains the official documentation for the VitaNova project.

VitaNova is a centralized blood donation and coordination platform designed to connect donors, patients, hospitals, and blood banks through an efficient digital system.

The documentation provides information about the system architecture, development process, database structure, APIs, security, testing procedures, and user interaction.
